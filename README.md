# 월하탄막 ~ Moonlit Barrage

동방홍마향(東方紅魔郷)의 게임 시스템을 오마주한 **종스크롤 탄막 슈팅 웹 게임**입니다.
캐릭터, 탄막 패턴, 그래픽, 효과음은 모두 오리지널이며, 외부 라이브러리나 이미지 없이 HTML 파일 하나로 동작합니다.

- 장르: 종스크롤 탄막 슈팅 (Bullet Hell)
- 분량: 1스테이지 (잡몹 웨이브 + 중간보스 + 보스 5페이즈)
- 난이도: Easy / Normal / Hard / Lunatic
- 모드: 게임 시작, 보스 연습

## 실행 방법

설치할 것이 없습니다.

1. 저장소를 내려받거나 클론합니다.
   ```bash
   git clone https://github.com/Jeonwol/Moonlit-Barrage.git
   ```
2. `index.html`을 크롬 등 최신 브라우저로 엽니다.
3. 게임 화면을 한 번 클릭한 뒤 키보드로 조작합니다.

> GitHub Pages(Settings → Pages → Branch: `main` / root)를 켜면 링크 하나로 바로 플레이할 수 있습니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| 방향키 | 이동 |
| Shift | 저속 이동 (피격 판정 표시) |
| Z | 사격 / 메뉴 결정 |
| X | 봄 / 메뉴 취소 |
| Esc, P | 일시정지 |
| M | 소리 켜기/끄기 |
| Enter, Space | 메뉴 결정 |

## 게임 시스템

### 플레이어
- **작은 피격 판정**: 실제 판정은 반지름 약 2px의 점입니다. Shift를 누르면 화면에 표시됩니다.
- **파워 (0~128)**: 파워 아이템으로 오르며, 단계에 따라 옵션이 2개 → 4개로 늘어납니다. 128(MAX)에 도달하면 화면의 탄이 모두 점수로 바뀝니다.
- **봄**: 화면의 탄을 지우고 약 3초간 무적이 됩니다.
- **데스봄**: 피격 직후 9프레임 안에 봄을 누르면 살아남습니다.
- **잔기 / 봄**: 시작 시 잔기 2, 봄 3. 피격될 때마다 봄은 3개로 초기화되고 파워가 16 줄어듭니다.

### 점수
- **그레이즈**: 탄을 아슬아슬하게 스칠 때마다 +500점.
- **점(点) 아이템**: 화면 위쪽에서 주울수록 고득점 (1,000 ~ 10,000점).
- **아이템 회수 라인**: 파워 MAX 상태로 화면 상단 라인 위에 올라가면 모든 아이템을 자동 회수합니다.
- **스펠카드 보너스**: 피격·봄 없이 스펠카드를 깨면 남은 시간에 비례한 보너스(50만 ~ 250만점).
- **익스텐드**: 800만 / 2,000만 / 4,000만점에서 잔기 +1.
- **클리어 보너스**: 남은 잔기 1개당 300만, 봄 1개당 100만점.

### 난이도
패턴은 같고 탄의 개수와 속도만 달라집니다.

| 난이도 | 탄 개수 | 탄 속도 |
| --- | --- | --- |
| Easy | ×0.55 | ×0.82 |
| Normal | ×1.0 | ×1.0 |
| Hard | ×1.45 | ×1.12 |
| Lunatic | ×1.9 | ×1.24 |

하이스코어는 난이도별로 브라우저(localStorage)에 저장되며, 보스 연습 기록은 저장되지 않습니다.

## 스테이지 구성

```
도입 웨이브 → 중간보스 노아 → 후반 웨이브 → WARNING → 보스 시즈쿠 메이라 → 클리어
```

**중간보스 — 노아 (숲그늘의 요정)**
- 통상: 서로 반대로 도는 쌀알탄 고리
- 요정부「반딧불 원무」: 보스 주위를 돌던 탄이 플레이어를 향해 가속

**보스 — 시즈쿠 메이라 (서리꽃의 수정술사)**
- 통상 1: 회전 탄 고리 + 조준 나이프
- 빙결부「서리꽃 만다라」: 퍼지던 탄이 얼어붙었다가 사방으로 풀려남
- 통상 2: 고정 방향 조준 연사 + 휘는 고리
- 환월부「붉은 달의 회랑」: 위에서 떨어지는 큰 탄 + 조준 나이프
- 종막「천 개의 등불」: 반대로 도는 가속 나선 두 개 + 큰 탄 고리

## 기술 구조

- **HTML5 Canvas 2D** 렌더링, 화면 640×480 (플레이 영역 384×448)
- **60fps 고정 타임스텝**: 모니터 주사율과 관계없이 같은 속도로 동작
- **WebAudio**로 효과음을 실시간 합성 (음원 파일 없음)
- 탄 스프라이트를 종류·색상별로 한 번만 그려 캐싱
- 원형 거리 비교로 충돌 판정 (판정 반지름은 그림보다 작게 설정)
- 스테이지는 `[프레임, 함수]` 이벤트 목록으로 정의되어, 목록만 추가하면 스테이지를 늘릴 수 있음

한 프레임의 처리 순서:

```
입력 → 스테이지 타임라인 → 플레이어 → 봄 → 보스 → 적 → 플레이어 탄 → 적 탄(피격·그레이즈) → 아이템 → 이펙트 → 렌더링
```
